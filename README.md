# Budget Familial Laetitia — V3.0

Version reconstruite sur une base propre avec fichiers séparés.

## Fichiers

- `index.html`
- `styles.css`
- `app.js`
- `manifest.webmanifest`
- `version.json`
- `icon.svg`

## Fonctions

- migration automatique des données V2 ;
- carte à débit différé le 4 ;
- prévision chronologique du compte ;
- prélèvements débités au clic ;
- dépenses, revenus immédiats et revenus futurs ;
- budgets par catégorie ;
- historique avec recherche ;
- modification des revenus, prélèvements et budgets ;
- sauvegarde, restauration et sauvegarde automatique ;
- interface iPhone plus propre et maintenable.
