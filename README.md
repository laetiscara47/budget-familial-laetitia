# Mon Budget Infinity

## Réalisé

- nouvelle identité Infinity ;
- indice de sérénité financière ;
- vue Aujourd’hui / Demain / 7 jours / 30 jours ;
- projections réglables sur 1, 3, 6 ou 12 mois ;
- synthèse familiale consolidée ;
- tableau de bord, patrimoine, crédits, objectifs, coffre et rapports conservés ;
- sauvegarde classique et sauvegarde chiffrée conservées ;
- interface installable sur l’écran d’accueil de l’iPhone.

## Limites honnêtes

Mon Budget Infinity reste une application web hébergée sur GitHub Pages.

Ne sont pas simulés :
- connexion bancaire automatique ;
- OCR automatique des tickets ;
- notifications système iPhone ;
- Face ID natif ;
- synchronisation entre appareils.
