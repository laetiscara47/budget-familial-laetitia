Version simplifiée et stable.

Principales fonctions :
- accueil compact ;
- statut Confortable / Attention / Risque ;

- agenda chronologique ;
- écran Comptes ;
- revenus et prélèvements récurrents ;
- sauvegarde locale et export JSON ;
